# urbanmart_product_sales-# UrbanMart Retail Sales - Product Sales Dataset

## 📊 Project Overview
This dataset focuses on **product-level sales**. The aim is to evaluate product performance, profitability, and trends across four stages:
1. Excel Analysis
2. SQL Analysis
3. Python Analysis
4. Dashboard Creation

---

## 🔹 Step 1: Excel Analysis
- Import `product_sales.csv` into Excel.
- Use PivotTables to analyze:
  - Revenue by product category
  - Profit margins
  - Regional sales distribution
- Create charts (stacked bar, line, scatter).

**Deliverables:**
- PivotTable reports
- Excel charts
- Summary workbook

---

## 🔹 Step 2: SQL Analysis
- Load dataset into MySQL/PostgreSQL.
- Run queries such as:
  - Highest revenue products
  - Category-wise profitability
  - Regional sales comparison
  - Year-over-year growth

**Deliverables:**
- SQL scripts (`product_sales_queries.sql`)
- Exported query results (CSV)

---

## 🔹 Step 3: Python Analysis
- Use Pandas for data cleaning and transformation.
- Perform EDA:
  - Profitability analysis
  - Category trends
  - Regional segmentation
- Visualize with Matplotlib/Seaborn.

**Deliverables:**
- Jupyter Notebook (`product_sales_analysis.ipynb`)
- Python scripts (`product_sales_analysis.py`)
- Visualizations (PNG/HTML)

---

## 🔹 Step 4: Dashboard
- Import cleaned dataset into Power BI/Tableau.
- Build interactive visuals:
  - Revenue overview
  - Category performance
  - Regional sales trends
  - Profitability analysis
- Add filters for category, region, and time.

**Deliverables:**
- Dashboard file (`product_sales_dashboard.pbix`)
- Screenshots of dashboard views
